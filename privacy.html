Privacy policy

プライバシーポリシー

最終更新日: 2026年10月12日

収集する情報

tsumé（以下「本アプリ」）は、氏名・メールアドレス・位置情報などの個人情報を収集しません。アカウント登録もありません。「みんなに見せる」で投稿したとき・通報したときだけ、下の「投稿と通報（みんなのデザイン）」に書いた情報（端末ごとにアプリが作った乱数から計算した値を含みます）を送ります。

端末内に保存する情報

「マイデザイン」に保存したデザインと選択条件、「描く」で描いた絵、AIで作ったシール絵、「パーツを取り込む」で切り抜いたパーツの画像、持っている色・パーツの一覧は、お使いの端末内（ブラウザまたはアプリの保存領域）にのみ保存されます。開発者や第三者のサーバーには送信されません。アプリを削除すると消去されます。ギャラリーで「出さない」にした作品・人、通報した作品、送った投稿の番号・ニックネームと、投稿・通報に使う端末ごとの乱数も、この端末の中だけに保存します（乱数そのものは送りません）。

通信

本アプリは、提案の生成・表示を端末内で行います。ウェブ版では表示用フォントの取得のために Google Fonts に接続することがあります。広告配信・アクセス解析・トラッキングは行いません。

「みんなのデザイン」を開くと、運営が選んだ作品の一覧（gallery.json）を GitHub Pages から読み込みます。このとき送る情報はありません（GitHub は、ページを開いた人の IP アドレスを安全のために記録します）。ギャラリーの「投稿」タブや「みんなに見せる」を開いたときは、投稿の一覧を、開発者が運営する中継サーバー（Cloudflare Workers）から読み込みます。このときも、あなたについての情報は送りません。中継サーバーは、使いすぎを防ぐために接続元の IP アドレスで短い時間の回数を数えますが、開発者は IP アドレスを保存しません。

AIによる読み取り（任意）

「ことばで咲く」「tsumé ソムリエ」「色を混ぜて作る」「シール工房」「AIでシール絵」「写真から作り方」で、AIを使うことに同意した場合に限り、入力した言葉（色や模様の名前を含む）、デザインの説明文、または選んだモチーフ・描き方・色を、開発者が運営する中継サーバー（Cloudflare Workers）を経由して Google の Gemini API に送信します。中継サーバーは AI に送った内容を保存・記録しません。Google での取り扱いは Gemini API の利用規約に従います。AI は18歳以上の方だけが使えます（同利用規約）。人の名前など個人がわかる言葉は入力しないでください（「〜さん」などの前の語は送信前に伏せます）。同意しない場合やオフにした場合は送信せず、端末内の辞書で動作します。AIで作ったシール絵は、この端末の中だけに保存します。

写真をAIに送る（任意）「写真から作り方」と、パーツを取り込むときの「AIにおまかせ」で、写真を送ることに別に同意した場合に限り、選んだ写真1枚を同じ中継サーバー経由で Google の Gemini API に送信します。送る前に端末の中で写真を小さくし（長い辺1536ピクセルまで）、撮影場所などの情報を取り除きます。中継サーバーと開発者は写真を保存・記録しません。人の顔や手が写らないようにしてください。この同意は「使い方」でいつでも取り消せます。

利用回数の記録費用の上限を守るため、中継サーバーは AI の機能ごとに1日の利用回数の合計（日付・機能・回数）だけを記録します。誰が使ったかは記録しません。

音声

音声案内と tsumé ソムリエの読み上げは、端末の音声合成機能を使い、外部には送信しません。作るモードの「声で操作する」、または色の名前を声で入れるマイクのボタンを押した場合に限り、マイクの音声がブラウザまたは OS の音声認識機能に渡されます（ブラウザによっては、その提供元のサーバーで処理されます）。本アプリは音声を保存しません。

写真と印刷

「写真から色を取る」で選んだ写真は、この端末の中だけで扱い、送信も保存もしません。シール工房で作ったシートの印刷・PDFは、この端末の中で作ります。

「パーツを取り込む」で撮った（選んだ）写真は、この端末の中でパーツごとに切り抜き、切り抜いた小さな画像だけをこの端末に保存します。元の写真は保存せず、送信もしません（「AIにおまかせ」を除きます。上の「写真をAIに送る」をご覧ください）。袋のバーコードの読み取りも、この端末の中で行います。共有リンクとギャラリーの投稿には、切り抜いた画像は入れません（色と大きさの近い、ふつうのパーツの絵に置きかえます）。

共有機能

「共有」を押したときだけ、あなたが選んだアプリ（メッセージ・SNS など）に、デザインの画像（手の絵・材料・目安・QRコード）と、デザインを開くリンクを渡します。画像とリンクはこの端末の中で作ります。画像の手の絵は、あなたが選んだ肌の色で描きます。リンクの「#d=」より後ろには、デザインのデータ（色・技法・パーツの位置・選んだ条件）が入ります。この部分はサーバーに送られず、リンクを開いた端末の中で読み取ります。肌の色・名前・写真はリンクに入りません。「レシピを文章で送る」を選んだときは、レシピの文章だけを渡します。

投稿と通報（みんなのデザイン）

「みんなに見せる」で投稿したときに限り、デザインのデータ（色・技法・パーツの位置・選んだ条件）・題名・ニックネームと、端末ごとにアプリが作った乱数から計算した値（ハッシュ。投稿の回数の制限と、通報の重なりを防ぐために使います）を、開発者が運営するサーバー（Cloudflare）に送って保存します。写真・肌の色・本名・メールアドレスは送りません。URL・メールアドレス・電話番号を含む投稿は受け付けません。運営が内容を見てから公開し、公開したデザイン・題名・ニックネームは、ほかの利用者が見られます。公開する一覧には、同じ人の作品をまとめて非表示にできるよう、ハッシュからさらに計算した短い符号を含めます（元の値には戻せません）。通報したときは、作品の番号と理由、同じ値（ハッシュ）を送ります。通報が3件たまった作品は自動で非表示になり、運営が確かめます。「この人の作品を出さない」は、この端末の中だけに保存します。投稿を消してほしいときは、下のお問い合わせ先へご連絡ください。18歳未満の方は、保護者の方と確かめてから投稿してください。
