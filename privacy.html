プライバシーポリシー

最終更新日: 2026年10月12日

対象年齢

tsumé（以下「本アプリ」）は、18歳以上の方を対象としています。

収集する情報

本アプリは、氏名・メールアドレス・位置情報などの個人情報を収集しません。アカウント登録もありません。「みんなに見せる」で投稿したとき・通報したときだけ、下の「投稿と通報（みんなのデザイン）」に書いた情報（ニックネームと、端末ごとにアプリが作った乱数から計算した値を含みます）を送ります。

端末内に保存する情報

「マイデザイン」に保存したデザインと選択条件、「描く」で描いた絵、AIで作ったシール絵、「パーツを取り込む」で切り抜いたパーツの画像、持っている色・パーツの一覧、「自然な声」で読み上げた声（最大300文）は、お使いの端末内（ブラウザまたはアプリの保存領域）にのみ保存されます。開発者や第三者のサーバーには送信されません。アプリを削除すると消去されます。ギャラリーで「出さない」にした作品・人、通報した作品、送った投稿の番号・ニックネームと、投稿・通報に使う端末ごとの乱数も、この端末の中だけに保存します（乱数そのものは送りません）。

通信

本アプリは、提案の生成・表示を端末内で行います。ウェブ版では表示用フォントの取得のために Google Fonts に接続することがあります。広告配信・アクセス解析・トラッキングは行いません。

「みんなのデザイン」を開くと、運営が選んだ作品の一覧（gallery.json）を GitHub Pages から読み込みます。このとき送る情報はありません（GitHub は、ページを開いた人の IP アドレスを安全のために記録します）。ギャラリーの「投稿」タブや「みんなに見せる」を開いたときは、投稿の一覧を、開発者が運営する中継サーバー（Cloudflare Workers）から読み込みます。このときも、あなたについての情報は送りません。中継サーバーは、使いすぎを防ぐために接続元の IP アドレスで短い時間の回数を数えますが、開発者は IP アドレスを保存しません。

AIによる読み取り（任意）

「ことばで咲く」「tsumé ソムリエ」「色を混ぜて作る」「シール工房」「AIでシール絵」「写真から作り方」で、AIを使うことに同意した場合に限り、入力した言葉（色や模様の名前を含む）、デザインの説明文、または選んだモチーフ・描き方・色を、開発者が運営する中継サーバー（Cloudflare Workers）を経由して Google の Gemini API に送信します。これらの機能で AI に送った内容を、開発者と中継サーバーは保存・記録しません。AI は18歳以上の方だけが使えます（Gemini API の利用規約）。人の名前など個人がわかる言葉は入力しないでください（「〜さん」などの前の語は送信前に伏せます）。同意しない場合やオフにした場合は送信せず、端末内の辞書で動作します。AIで作ったシール絵は、この端末の中だけに保存します。AIを使うことに同意すると、読み上げも「自然な声」になります（下の「音声」をご覧ください）。ギャラリーへの投稿でも AI を使います（下の「投稿と通報（みんなのデザイン）」をご覧ください）。

Google での取り扱いGoogle に送った内容の取り扱いは、Gemini API の利用規約に従います。Google は、有料で使う場合でも、禁止された使い方を見つけるため、送られた内容を限られた期間記録することがあります（同利用規約）。

写真をAIに送る（任意）「写真から作り方」と、パーツを取り込むときの「AIにおまかせ」で、写真を送ることに別に同意した場合に限り、選んだ写真1枚を同じ中継サーバー経由で Google の Gemini API に送信します。送る前に端末の中で写真を小さくし（長い辺1536ピクセルまで）、撮影場所などの情報を取り除きます。中継サーバーと開発者は写真を保存・記録しません（Google での取り扱いは上と同じです）。人の顔や手が写らないようにしてください。この同意は「使い方」でいつでも取り消せます。

利用回数の記録費用の上限を守るため、中継サーバーは AI の機能ごとに1日の利用回数の合計（日付・機能・回数）を記録し、30日で消します。上の機能では、誰が使ったかは記録しません。

音声

音声案内・tsumé ソムリエ・色の混ぜ方などの読み上げは、「端末の声」を選んだ場合（または「自然な声」に同意していない場合）、端末の音声合成機能を使い、外部には送信しません。

読み上げ（自然な声）「自然な声」を選んだ場合（AIを使うことに同意した場合を含みます）に限り、読み上げる文（作り方の手順・tsumé ソムリエの説明・色の混ぜ方など。あなたが入力した色の名前を含むことがあります）を、中継サーバー（Cloudflare Workers）を経由して Google の Gemini API、または Google Cloud Text-to-Speech（Google Cloud の音声合成サービス）に送り、声にします。中継サーバーは、同じ文の声を最大30日間キャッシュします（保存するのは文と声だけで、誰が使ったかは残しません）。作った声は、次から通信しないよう、お使いの端末の中にも保存します（最大300文。古いものから消します）。「端末の声」を選べば送信しません。この設定は「使い方」でいつでも変えられます。Google での取り扱いは、上の「AIによる読み取り」と同じです。自然な声は18歳以上の方向けです。Google Cloud Text-to-Speech に送った文の取り扱いは、Google Cloud の利用規約に従います。

マイク作るモードの「声で操作する」、または色の名前を声で入れるマイクのボタンを押した場合に限り、マイクの音声がブラウザまたは OS の音声認識機能に渡されます（ブラウザによっては、その提供元のサーバーで処理されます）。本アプリはマイクの音声を保存しません。

写真と印刷

「写真から色を取る」で選んだ写真は、この端末の中だけで扱い、送信も保存もしません。シール工房で作ったシートの印刷・PDFは、この端末の中で作ります。

「パーツを取り込む」で撮った（選んだ）写真は、この端末の中でパーツごとに切り抜き、切り抜いた小さな画像だけをこの端末に保存します。元の写真は保存せず、送信もしません（「AIにおまかせ」を除きます。上の「写真をAIに送る」をご覧ください）。袋のバーコードの読み取りも、この端末の中で行います。共有リンクとギャラリーの投稿には、切り抜いた画像は入れません（色と大きさの近い、ふつうのパーツの絵に置きかえます）。

共有機能

「共有」を押したときだけ、あなたが選んだアプリ（メッセージ・SNS など）に、デザインの画像（手の絵・材料・目安・QRコード）と、デザインを開くリンクを渡します。画像とリンクはこの端末の中で作ります。画像の手の絵は、あなたが選んだ肌の色で描きます。リンクの「#d=」より後ろには、デザインのデータ（色・技法・パーツの位置・選んだ条件）が入ります。この部分はサーバーに送られず、リンクを開いた端末の中で読み取ります。肌の色・名前・写真はリンクに入りません。「レシピを文章で送る」を選んだときは、レシピの文章だけを渡します。

投稿と通報（みんなのデザイン）

「みんなに見せる」で投稿したときに限り、デザインのデータ（色・技法・パーツの位置・選んだ条件）・題名・ニックネームと、端末ごとにアプリが作った乱数から計算した値（ハッシュ。投稿の回数の制限、通報の重なりを防ぐこと、投稿禁止に使います）を、開発者が運営するサーバー（Cloudflare）に送って保存します。写真・肌の色・本名・メールアドレスは送りません。URL・メールアドレス・電話番号を含む投稿は受け付けません。投稿できるのは18歳以上の方だけです。投稿のきまりは「投稿のきまり（利用規約）」をご覧ください。

AI と運営による確認投稿の画面で同意した場合に限り、題名・ニックネーム・デザインの中の文字（色の名前など）を、中継サーバーを経由して Google の Gemini API に送り、載せてよいかを自動で確かめます。問題がないと判断したものはすぐ公開します。判断に迷ったものと、AI で確かめられなかったものは、運営が確かめてから公開します。不適切と判断したものは保存しません。AI の判定（問題がない・迷う・不適切と、40字までの理由）は、投稿と一緒に保存します。AI で確かめる回数を抑えるため、ハッシュごとに1日の回数を数えます。運営が確かめるときは、Anthropic の AI（Claude）を使うことがあります。このとき、確かめる投稿の題名・ニックネーム・デザインのデータ、通報の件数と理由、ハッシュの先頭の数文字を Anthropic に送ります。公開したデザイン・題名・ニックネームは、ほかの利用者が見られます。公開する一覧には、同じ人の作品をまとめて非表示にできるよう、ハッシュからさらに計算した短い符号を含めます（元の値には戻せません）。

通報通報したときは、作品の番号と理由、同じ値（ハッシュ）を送ります。「投稿者も通報する」を選んだときは、その作品の投稿者への通報としても数えます。その作品への最初の通報のとき、AI（Gemini）がもう一度確かめ、不適切と判断したものはすぐ非表示にします。通報が3件たまった作品も自動で非表示になり、運営が確かめます。運営は、きまりに反する投稿をした端末からの投稿を止めること（投稿禁止）があり、そのためにハッシュを記録します。「この人の作品を出さない」は、この端末の中だけに保存します。

保存期間公開中の投稿は、投稿から1年で自動で消します。審査待ちの投稿は投稿から30日、非表示にした投稿は非表示にしてから180日で消します。通報の記録（日時・理由・ハッシュ）は180日、投稿禁止の記録（ハッシュ）は1年、AI の利用回数の記録は30日で消します。投稿した本人から依頼があれば、期間の前でもすぐ消します。消したあとも、サーバーの復旧用の記録（Cloudflare D1 の Time Travel）に最大30日残ることがあります。
